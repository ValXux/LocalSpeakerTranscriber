# Ejemplos ficticios

Esta carpeta contiene datos pequenos y ficticios para documentar formatos de
entrada y salida. No contiene audios reales ni transcripciones privadas.

- `legacy_google_stt_sample.csv`: ejemplo del formato CSV legacy de Google STT.
- `transcript_unificado_sample.csv`: ejemplo minimo de salida CSV del pipeline.
- `transcripcion_sample.txt`: ejemplo minimo de salida TXT legible.

Para ejecutar el pipeline real, coloca tu audio fuera de Git, por ejemplo en
`data/audio/mi_audio.mp3`.
